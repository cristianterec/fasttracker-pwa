# FastTrackers PWA

Gestion des patients aux urgences.

## Conformité légale

Cette application respecte les exigences de la législation française et du RGPD concernant les données de santé :

- aucune donnée nominative ne doit être saisie ;
- les informations sont stockées de manière sécurisée au sein de l'Union européenne ;
- les accès sont protégés par un code PIN et une déconnexion automatique après 10 minutes d'inactivité ;
- chaque utilisateur est responsable du respect de la confidentialité et de l'autorisation de traitement des données.

## Fonctionnalités

- Suivi des patients par couleur de triage
- Statistiques personnelles en temps réel
- Mode sombre/clair
- PWA utilisable hors ligne

## Développement

Pour vérifier le code :

```bash
node --check app.js
```
